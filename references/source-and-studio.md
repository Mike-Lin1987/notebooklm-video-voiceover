# 來源與 NotebookLM Studio

先盤點使用者原影片及說明資料，建立來源清單和可核對的主張。可用 `../assets/source-packet-template.md` 整理；標出事實、示意設定、推論與不可宣稱事項。逐項核對中文術語、英文字、數值、單位、動作順序和安全／性能界線。資訊衝突時先追原來源或請使用者決定，不把猜測寫成規格。

在 NotebookLM 中選對筆記本，確認預計使用的來源已處理完成且勾選狀態正確，再操作 Studio。自訂提示描述語言、說話形式、主題順序、重點及禁忌；預期時長是偏好，Audio Overview 不是逐字 TTS。生成後核對輸出名稱與狀態，取得完成的原音檔。下載控制逾時，檢查下載目錄中具體檔案的存在、大小、mtime 和媒體 metadata，避免重複產生版本。

可依本次來源改寫短提示：「請用繁體中文，以清楚自然的設備解說，依序說明〔主題／章節〕。準確使用〔術語與單位〕，區分來源事實與動畫示意；不要宣稱〔未驗證的性能／安全結論〕。請留出章節換畫面的停頓。」說話形式和時長只填使用者確有指定且當前 Studio 可設定的項目；不得將提示當成逐字或固定秒數保證。

逐段核對自動轉錄或可得文字與原來源的語意；尤其檢查專有名詞、數字、單位、動作互鎖及過度宣稱。轉錄不是人工聽辨。若內容確實不符，可以在原授權內修正來源或提示並重新生成；保存版本與採用理由。對外上傳來源或把原音回傳 NotebookLM 做轉錄，須先核對當次授權涵蓋該資料與操作。

官方參考（2026-09-29 查核）：[Audio Overview 說明](https://support.google.com/gemininotebook/answer/16212820?hl=en) 說明來源摘要、可用形式與下載；具體控制項以當前帳戶介面為準。[匯入音訊說明](https://support.google.com/gemininotebook/answer/16215270?hl=en) 說明音檔作為來源的轉錄處理。這些功能不代表逐字配音或可靠句級時間戳。
